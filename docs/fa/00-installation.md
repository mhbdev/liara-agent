# ۰. شروع کار در پروژه خودتان

به **Node.js نسخه ۲۰ یا بالاتر**، **Git** و ایجنت کدنویسی دلخواهتان نیاز دارید.
در ویندوز Git for Windows را نصب کنید؛ برای ابزارهای shell لیارا در مراحل
بعدی از ترمینال Git Bash آن استفاده کنید. اتصال حساب لیارا بعد از نصب است.

## ۱. یک دستور اجرا کنید

ترمینال را در **پوشه وب‌سایت خودتان** باز کنید و اجرا کنید:

```bash
npx --yes github:mhbdev/liara-agent
```

نصب‌کننده پکیج را دریافت می‌کند و فایل‌های پروژه را برای **Claude Code،
Codex، Cursor، Windsurf، Aider و Gemini** با هم آماده می‌کند. نیازی به انتخاب
سرویس، کپی دستی فایل‌ها، مدیریت پوشه منبع جداگانه یا نصب سراسری ایجنت‌ها ندارید.
وابستگی‌ها و فایل `package.json` وب‌سایت شما تغییر نمی‌کنند.

## ۲. ایجنت را دوباره باز کنید و درخواست بدهید

همان پوشه وب‌سایت را در ایجنت کدنویسی باز کنید، چت تازه‌ای شروع کنید و بگویید:

```text
کمک کن حساب لیارا را وصل کنم و این پروژه را برای محیط آزمایشی تنظیم کنم.
```

در Claude Code می‌توانید `/liara-login` و بعد `/liara-setup` را هم اجرا کنید.
ایجنت بررسی ابزارها و اتصال حساب را قدم‌به‌قدم راهنمایی می‌کند.
**توکن را فقط در ترمینال خودتان وارد کنید**، نه در چت. خود نصب‌کننده هیچ رمزی
نمی‌خواند، حسابی را وصل نمی‌کند و چیزی منتشر نمی‌کند.

مسیر شروع همین است. اگر ترجیح می‌دهید مراحل بعدی را خودتان انجام دهید،
[شروع سریع](01-quickstart.md) را ببینید. کنترل‌های مخصوص هر محیط و بررسی
فعال‌سازی در [راهنمای سرویس‌ها](04-providers.md) آمده است.

## اگر پروژه از قبل تنظیمات ایجنت دارد

نصب‌کننده حالت‌های معمول را خودش مدیریت می‌کند:

- دستورالعمل‌های فعلی پروژه را نگه می‌دارد و بخش مشخصی برای لیارا اضافه می‌کند.
- مجوزها و هوک‌های Claude را با حفظ ورودی‌های فعلی ادغام می‌کند.
- تنظیمات فعلی Codex و Aider را حفظ می‌کند. اگر Aider تنظیمات دارد، دستور
  دقیق شروع با فایل‌های لیارا را در پایان نمایش می‌دهد.
- قواعد نادیده‌گیری رمزها، اسکریپت‌ها، نقش‌ها و فایل‌های مرجع را اضافه می‌کند.
- اگر فایل هم‌نام پکیج متفاوت یا مسیر مقصد لینک باشد، قبل از نوشتن متوقف
  می‌شود و مسیرهای نیازمند بازبینی را می‌گوید؛ گزینه بازنویسی اجباری ندارد.

فایل `.env`، پوشه `.liara/`، وضعیت محلی، تنظیمات برنامه و README وب‌سایت
دست‌نخورده می‌مانند. اجرای دوباره همان نسخه تغییری نمی‌دهد. تفاوت فایل‌ها
را در گیت پروژه بازبینی کنید.

## اختیاری: پیش‌نمایش یا انتخاب پوشه

دیدن تغییرات پیشنهادی بدون نوشتن فایل:

```bash
npx --yes github:mhbdev/liara-agent --dry-run
```

نصب در پوشه مشخص یک وب‌سایت:

```bash
npx --yes github:mhbdev/liara-agent --project "/path/to/my website"
```

## دانلود یا کلون را ترجیح می‌دهید؟

از پوشه وب‌سایت:

```bash
git clone https://github.com/mhbdev/liara-agent.git ../liara-agent-pack
node ../liara-agent-pack/bin/install.mjs
```

دانلود ZIP هم ممکن است: دستور `node /path/to/liara-agent/bin/install.mjs` را
از پوشه وب‌سایت اجرا کنید. منبع دانلودشده را بیرون از وب‌سایت نگه دارید.

## قبل از کار با سایت

نصب فایل‌ها ثابت نمی‌کند هوک در محیط فعال شده یا انتشار سالم است. از نقش
اتصال راهنمایی بگیرید یا [شروع سریع](01-quickstart.md) را دنبال کنید. عملیات
لیارا به ابزار خط فرمان لیارا، `curl` و `sh` نیاز دارد؛ ایجنت ابزارهای
نصب‌نشده را توضیح می‌دهد.

پکیج فعلی دو شکست ثبت‌شده در تست قفل دارد.
[شکاف‌های امنیتی شناخته‌شده](07-security.md) را ببینید؛ تست ناموفق را رد نکنید
و محافظت اجرای دستور را تأییدشده اعلام نکنید. نصب‌کننده این قفل‌ها را تغییر نمی‌دهد.

## به‌روزرسانی بعدی

همان دستور نصب را دوباره اجرا کنید. فایل‌های یکسان دست‌نخورده می‌مانند. اگر
فایل نصب‌شده با نسخه دریافتی متفاوت باشد، نصب قبل از نوشتن متوقف می‌شود تا
تغییرات را بازبینی کنید. اسکریپت‌ها یا تغییرات محلی بی‌اطلاع جایگزین نمی‌شوند
و رمزها و تأییدیه‌ها بین پروژه‌ها کپی نمی‌شوند.
